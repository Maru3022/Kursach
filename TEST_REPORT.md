# Отчёт о тестировании

Дата: 30.10.2026. Среда: Windows, MSVC 19.44, CMake из CLion 2025.2.4, raylib 5.5.

## Автоматические проверки

Release и Debug успешно собраны MSVC и прошли CTest. В каждой конфигурации тестовый исполняемый файл выполнил 4969 assertion-проверок, включая:

- все 8 линий победы, ничью, занятые и неверные координаты;
- чередование X/O и запрет хода после результата;
- только свободные случайные ходы;
- немедленную победу, блокирование, создание и защиту от вилок Medium;
- исчерпывающий обход всех допустимых ответов человека против Hard за X и за O;
- серии до 1, 3 и 5 побед, ничьи и запрет двойного учёта;
- продвижение четвертьфинал → полуфинал → финал и чемпиона;
- автоматические матчи компьютер–компьютер для всех сочетаний уровней;
- запись/чтение статистики и полного турнира.

Результат CTest: `100% tests passed, 0 tests failed`.

## Аудит компьютерных соперников

Настоящих интеграций с OpenAI, ChatGPT, LLM, нейросетями, внешними моделями, API, HTTP-клиентами или облачными сервисами в исходном проекте не обнаружено. Исходный `ai.cpp` уже содержал локальные Random/Rules/Minimax, поэтому сетевые компоненты удалять не потребовалось. Собственный модуль переименован в `computer.h/.cpp`, а его API — в `getRandomMove`, `getMediumMove`, `getBestMove` и `getComputerMove`.

Raylib 5.5 остаётся единственной загружаемой CMake сторонней библиотекой и используется только для графического интерфейса. После сборки приложение и выбор ходов работают без сети. Готовый Windows-файл: `dist/TicTacToe.exe`; SHA-256: `73FFFD43CF2A52E9BC7382B4908213752CABCE047BEB6FD88F53C9C2D9AD3A23`.

## Исправленные проблемы

- прежний «турнир» двух игроков заменён сеткой на 8 участников;
- повреждённые русские строки заменены корректным UTF-8;
- добавлены отсутствовавшие сохранение турнира, отдельная серия и компьютер–компьютер;
- устранён конфликт имён цветов UI с макросами raylib/Win32, найденный Release-сборкой;
- добавлена защита от повторного учёта партии и недоступных матчей.

## Ограничения проверки

Выполнен реальный контрольный запуск Release EXE и сделан скриншот: кириллица и цвета корректны; найденные консольное окно и неудачное положение окна исправлены. Полный ручной проход всех кнопок и скриншоты каждого экрана в этой сессии не выполнены. Переносимость структуры подготовлена статической линковкой, однако запуск на физически другом Windows-компьютере не выполнялся. Эти две проверки следует провести перед окончательной сдачей.
