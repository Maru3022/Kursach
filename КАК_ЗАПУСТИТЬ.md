# Как запустить «Крестики-нолики»

## Самый простой способ

1. Откройте папку `dist`.
2. Запустите файл `TicTacToe.exe` двойным щелчком.
3. Не перемещайте `TicTacToe.exe` отдельно от папки `assets`: в ней находится шрифт интерфейса.

Путь к готовой программе внутри проекта:

```text
dist\TicTacToe.exe
```

Интернет, CLion и установка дополнительных библиотек для запуска готовой программы не нужны.

## Как начать игру

В главном меню доступны следующие режимы:

- **Быстрая игра** — одна партия;
- **Серия матчей** — игра до выбранного количества побед;
- **Турнирная сетка** — турнир на восемь участников;
- **Статистика** — результаты быстрых партий;
- **Правила** — краткое описание игры и уровней компьютера.

При настройке участника можно выбрать:

- **Человек** — ходы выполняются мышью;
- **Компьютер: лёгкий** — случайные ходы;
- **Компьютер: средний** — победа, блокировка, центр, случайный ход;
- **Компьютер: сложный** — оптимальная игра по алгоритму Minimax.

Можно запускать человека против человека, человека против компьютера или двух компьютеров друг против друга.

## Управление

- Нажмите левой кнопкой мыши на свободную клетку, чтобы сделать ход.
- Символ `X` всегда ходит первым.
- Для новой партии или возврата в меню используйте кнопки внутри приложения.
- Чтобы закрыть программу, выберите **Выход** либо закройте окно.

## Где хранятся сохранения

Статистика и незавершённый турнир сохраняются в:

```text
%LOCALAPPDATA%\TicTacToe
```

## Если программа не запускается

1. Убедитесь, что рядом с `TicTacToe.exe` находится папка `assets`.
2. Запускайте программу из распакованной папки, а не непосредственно из архива.
3. Если Windows показывает предупреждение SmartScreen, проверьте, что запускается файл из папки этого проекта, затем выберите **Подробнее → Выполнить в любом случае**.
4. Если шрифт или русский текст не отображаются, скопируйте всю папку `dist` заново, включая `assets\fonts\DejaVuSans.ttf`.

## Запуск из PowerShell

Из корневой папки проекта выполните:

```powershell
Start-Process -FilePath ".\dist\TicTacToe.exe" -WorkingDirectory ".\dist"
```
