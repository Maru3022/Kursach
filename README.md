# Крестики-нолики

Курсовой проект: игра 3×3 с графическим интерфейсом raylib, C++17 и CMake. Есть игра вдвоём, игра с компьютером, три сложности, турнир до 3/5/7 побед, статистика и правила.

## Файлы

- `src/game.*` — поле, ходы, победа и ничья.
- `src/ai.*` — случайный ход, защита и Minimax.
- `src/tournament.*` — счёт и смена первого игрока.
- `src/statistics.*` — чтение и запись текстовой статистики.
- `src/interface.*`, `src/main.cpp` — экраны и цикл raylib.
- `tests/game_tests.cpp` — проверки логики, включая перебор ходов человека.
- `assets/fonts` — шрифт DejaVu Sans с кириллицей и лицензией.

## Игра

X начинает первым. Победа — три одинаковых символа по горизонтали, вертикали или диагонали. Заполненное поле без победителя означает ничью. В лёгком режиме компьютер выбирает случайную свободную клетку. В среднем ищет немедленную победу, блокирует угрозу, берёт центр или делает случайный ход. В сложном Minimax оценивает каждое продолжение: +10 за победу компьютера, −10 за победу человека, 0 за ничью. В турнире после каждой партии участники меняются X/O; ничьи не входят в счёт побед. Статистика обычных партий и завершённых турниров учитывается отдельно в `statistics.txt` внутри `%LOCALAPPDATA%/TicTacToe` на Windows или `~/.local/share/TicTacToe` на Linux.

## CLion и Windows EXE

Откройте корень проекта в CLion, дождитесь конфигурации CMake и запустите цель `TicTacToe`. Нужен CMake 3.20+, компилятор C++17 и доступ к GitHub при первой загрузке raylib 5.5 через FetchContent. Для Windows используйте Release: `cmake -S . -B build-release -DCMAKE_BUILD_TYPE=Release`, затем `cmake --build build-release --config Release`. Исполняемый файл имеет имя `TicTacToe.exe`. Для отдельной папки выполните `cmake --install build-release --prefix dist --config Release`; перенесите всю папку `dist`, включая `assets` и `README.txt`. Если применяется MinGW, проверьте зависимости EXE на целевом ПК. Полная переносимость без проверки на чистой Windows не гарантирована.

Тесты: `cmake -S . -B build-tests -DBUILD_GAME=OFF && cmake --build build-tests && ctest --test-dir build-tests --output-on-failure`. Шрифт должен находиться в `assets/fonts` рядом с EXE. Приложение не требует сетевых сервисов. Известное ограничение: в текущей Linux-среде графическая и Windows-сборка ещё не подтверждены.
